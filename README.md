## 🔎 Buscador de Nomes

<p>Aplicação web em React que consome a "API Nomes" do IBGE com a finalidade de retornar a quantidade de pessoas que possuem um nome em específico.</p>

### 📚 Conceitos aplicados 

- ReactJS
- Props
- Renderização condicional
- Eventos DOM
- Hooks
- Requisições HTTP

### 🖥️ Instalando o projeto

```bash
# Clone o repositório
$ git clone https://github.com/olibpedro/buscador-de-nomes.git

# Instale as dependências
$ npm install

# Execute a aplicação em modo de desenvolvimento
$ npm run dev
```
